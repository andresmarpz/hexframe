- The first build that records games. It has not run on a real Windows PC yet, so expect rough edges.
- Starts recording when the game finishes loading and stops a few seconds after the Nexus falls.
- Saves each match as an MP4 with a JSON event timeline and highlight clips.
- Review screen with a video player and event markers. Click a marker to jump to it.
- `greyscreen-cli doctor` now runs a short capture and encoder test. `greyscreen-cli record --seconds 10` records a test file.
