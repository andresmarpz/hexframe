version: 0.1.9-preview.11
date: 2026-11-21
title: Setup window, smoother playback and feedback
---

- First install opens a setup window with a Start with Windows option, and Greyscreen now shows in Installed apps.
- Pausing no longer jumps back a second or two, videos no longer get stuck near the end, and the seek bar's dot follows playback.
- Death review plays again when you press play after a death ends.
- Speed is a menu, so normal speed is one click away; volume opens a slider when you hover the speaker.
- The games list now sits inside the main panel instead of a second sidebar, and you can drag to resize the sidebar and the list.
- In narrow windows the events panel moves below the video so the player keeps its full width.
- Delete asks in a centered dialog, wherever you start it.
- Pages, games and Settings sections switch instantly, without animations.
- Search boxes only show the clear button when there is text.
- New Send feedback button in the sidebar, dock and Settings. Sending isn't live yet; Copy report works.
