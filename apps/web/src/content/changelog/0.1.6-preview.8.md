title: New layout and review
---

- New layout with a Home and Recordings sidebar; Settings moved to a gear icon.
- New Home screen shows live recording, last game, recent games, weekly stats, and recent clips.
- Press F9 in game to save the last 30 seconds as a clip.
- Rebind any shortcut, including key combinations, in the new Keybinds tab in Settings.
- Smaller files at similar quality using Balanced, High, and Max presets; size estimate sits under Quality.
- Optional storage limit deletes the oldest full-game videos first while keeping your clips.
- Automatic updates check GitHub for new versions and install them after your game ends.
- Seek bar shows event markers and clip ranges; hover any event for kill or tower details.
- Click an event to jump 5 seconds before it, or filter deaths, kills, and objectives.
- Player adds ±5 s buttons, 0.25× to 2× speed, mute, frame step, and fullscreen theater mode.
- Recordings list shows champion icons, Victory or Defeat, KDA, relative dates, filters, and Recycle Bin delete.
- Windowed recordings crop out title bars and borders; the sidebar shows elapsed time while recording.
- Home adds a Record games switch, clearer event colours, Retry on failure, and Stop confirmation.
- Settings adds a cursor visibility toggle and lists your display's real resolutions.
- Single .exe installs with Start Menu, uninstaller, Start with Windows, in-place updates, and refreshed icon.
