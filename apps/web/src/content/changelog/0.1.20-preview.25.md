title: Filter out-of-order GPU frames during capture
---

- Drops stale, out-of-order game frames delivered by Windows capture (for example with NVIDIA Fast Sync enabled) before encoding, preventing brief backward-in-time frame stutters in recordings.
- Logs per-second dropped rewind counts in recording diagnostics so capture stalls and GPU frame-order glitches are easier to spot.
