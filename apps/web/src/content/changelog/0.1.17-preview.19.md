date: 2026-11-21
title: Smoother recordings on high refresh monitors
---

- Fixed recordings that captured only 48 new frames a second on 144 Hz monitors, which made 60 fps videos stutter slightly. Greyscreen now matches its timing to your monitor's refresh rate.
- Greyscreen asks Windows for higher graphics priority while recording, so a game that uses the whole graphics card drops fewer frames.
- Detailed recording diagnostics now note each second whether the game was the active window.
- Greyscreen reopens maximized if you closed it maximized.
